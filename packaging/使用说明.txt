AI 记忆总结工具（Windows 版）
================================

运行方法
--------
1. 请先把收到的 ZIP 完整解压到普通文件夹，不要直接在压缩包里运行。
2. 打开“AI记忆总结工具”文件夹。
3. 双击“AI记忆总结工具.exe”。
4. 粘贴 ChatGPT、DeepSeek 或豆包分享链接，选择导出模式后开始生成。

API KEY
-------
- “仅抓取对话”不需要 API KEY。
- 普通版、极简版或详细版需要在右上角齿轮中配置至少一个 API KEY。
- 密钥保存于当前 Windows 用户的凭据管理器，不写入程序目录、日志或导出文件。
- 只配置 Silicon Flow 时会直接使用 Silicon Flow；配置 Gemini 时优先使用 Gemini。

数据保存位置
------------
- 右上角齿轮包含“API KEY 设置”和“数据保存位置”两个页面。
- 运行数据默认保存在 %LOCALAPPDATA%\AI Memory Summary，可改到其他磁盘。
  运行数据包括浏览器登录会话、脱敏日志、总结缓存和显式启用的调试快照。
- 结果默认保存位置初始不设置；设置后，开始生成时只询问保存名称，
  不再重复询问目录。清除该设置即可恢复原来的目录与文件名选择器。
- 更改运行数据位置不会自动搬移或删除旧数据，授权登录可能需要重新登录一次。
- 两个目录路径只保存在当前 Windows 用户注册表中，不会上传。

隐私与联网
----------
- 抓取在本机内置浏览器中完成。
- 只有选择总结模式时，对话及可用附件才会通过 HTTPS 发送给所选模型服务。
- 程序不会把密钥或对话发送给开发者的电脑。
- 选择“授权登录”时，登录 Cookie 保存在当前 Windows 用户的本地应用数据目录。
- 分享链接只以站点域名和不可逆短指纹写入本地运行日志，不记录完整链接。

常见问题
--------
- Windows 首次运行可能显示 SmartScreen 提示，这是未购买代码签名证书导致的。
  请先确认文件来自可信发送者，再选择“更多信息”→“仍要运行”。
- 若安全软件隔离程序，请不要直接关闭安全软件；先核对来源并重新扫描 ZIP。
- 移动程序时必须移动整个文件夹，不能只复制 EXE。
- 导出 Markdown 若带图片，请连同同名 _images 文件夹一起发送或移动。

本地数据位置
------------
默认：%LOCALAPPDATA%\AI Memory Summary

可在右上角齿轮的“数据保存位置”中更改。目录中可能包含授权登录产生的
浏览器会话、已脱敏运行日志和总结缓存。API KEY 位于 Windows 凭据管理器，
条目服务名为“AI Memory Summary”。
