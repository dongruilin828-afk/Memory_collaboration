AI 记忆总结工具（Windows 轻量版）
======================================

运行方法
--------
1. 请把收到的 ZIP 完整解压到普通文件夹，不要直接在压缩包里运行。
2. 打开“AI记忆总结工具_轻量版”文件夹。
3. 双击“AI记忆总结工具_轻量版.exe”。
4. 粘贴 ChatGPT、DeepSeek 或豆包分享链接，选择导出模式后开始生成。

浏览器要求
----------
- 轻量版不内置浏览器，会优先调用本机 Microsoft Edge。
- 如果 Edge 无法启动，程序会自动尝试 Google Chrome。
- 如果两者都不可用，程序会提示安装其中一个浏览器或下载全量版。
- 建议保持浏览器自动更新。请勿在程序运行时卸载或强制结束所用浏览器。

API KEY
-------
- “仅抓取对话”不需要 API KEY。
- 普通版、极简版或详细版需要在右上角齿轮中配置至少一个 API KEY。
- 密钥保存于当前 Windows 用户的凭据管理器，不写入程序目录、日志或导出文件。
- 只配置 Silicon Flow 时会直接使用 Silicon Flow；配置 Gemini 时优先使用 Gemini。

隐私与联网
----------
- 网页抓取由本机 Edge 或 Chrome 完成。
- 只有选择总结模式时，对话及可用附件才会通过 HTTPS 发送给所选模型服务。
- 程序不会把密钥或对话发送给开发者的电脑。
- Edge 与 Chrome 的登录 Cookie 分别保存在当前 Windows 用户的本地应用数据目录。
- 分享链接只以站点域名和不可逆短指纹写入本地运行日志，不记录完整链接。

常见问题
--------
- Windows 首次运行可能显示 SmartScreen 提示，这是未购买代码签名证书导致的。
  请先确认文件来自可信发送者，再选择“更多信息”→“仍要运行”。
- 若安全软件隔离程序，请不要关闭安全软件；先核对来源和 SHA-256。
- 移动程序时必须移动整个文件夹，不能只复制 EXE。
- 导出 Markdown 若带图片，请连同同名 _images 文件夹一起发送或移动。

本地数据位置
------------
%LOCALAPPDATA%\AI Memory Summary

其中可能包含授权登录产生的浏览器会话和已脱敏运行日志。API KEY 位于 Windows
凭据管理器，条目服务名为“AI Memory Summary”。
