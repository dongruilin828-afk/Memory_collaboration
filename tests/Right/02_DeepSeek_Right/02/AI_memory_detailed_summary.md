- **学习要点｜Python 之禅的内容与核心思想**：Python 之禅（The Zen of Python）是 Tim Peters 在1999年编写的19条编程格言，输入 import this 可查看。核心思想包括可读性至上、明确优于隐晦、克制与实用并存。AI 给出了全部19条英文原文及中文意译。
- **学习要点｜Python 之禅与面向对象编程的联系**：AI 将 Python 之禅与之前学习的 OOP 概念联系：类和实例本质上创建了命名空间，对应“命名空间是一个绝妙的主意”；区分类变量和实例变量体现“明了胜于晦涩”；复杂的类继承设计违背“如果实现很难解释，那它就是个坏主意”。
- **学习要点｜MyClass 代码中 i 是类变量的确认及查找原理**：在用户上传的代码中，i=12345 定义在 MyClass 类中且在所有方法之外，因此 i 是类变量。访问 x.i 时，Python 先查找实例 x 自身是否有 i，没有再去类 MyClass 中查找，因此输出 12345。
- **学习要点｜通过实例给类变量赋值会造成遮蔽**：通过实例名给类变量赋值（如 x.i = 888）不会改变类变量 MyClass.i，而是在实例 x 中新建一个同名的实例变量，从而遮蔽类变量。建议通过类名 MyClass.i 修改类变量，避免混乱。
- **学习要点｜类变量、实例变量、局部变量的区分**：三类变量按定义位置、作用域、生命周期和共享方式区分：类变量定义在类中所有方法之外，被所有实例共享，随类加载创建；实例变量定义在方法内并用 self/this 修饰，每个实例独享，随对象创建；局部变量定义在方法内部或代码块中，仅限该方法内使用，方法执行完毕销毁，不共享。
- **学习要点｜类的实例与对象的关系**：类的实例就是对象。类是抽象模板/图纸，对象是根据类实例化出来的具体实体。通过类名()创建对象的过程叫实例化，结果叫实例。在面向对象编程中，类的实例与对象可以画等号。
- **学习要点｜数据成员的定义与分类**：数据成员是类中用来存放数据的变量。按图片定义，类变量或实例变量用于处理类及其实例对象的相关数据。数据成员分为类变量（定义在类中方法外，所有实例共享一份）和实例变量（定义在方法内，通常用 self 修饰，每个实例独立一份）。
- **重要建议｜图片中局部变量作用域表述不严谨的纠正**：AI指出上传图片中关于局部变量“只作用于当前实例的类”的表述不严谨，局部变量实际只作用于定义它的那个方法内部，离开该方法即销毁，同类其他方法也无法访问。用户未对纠正做出确认。
