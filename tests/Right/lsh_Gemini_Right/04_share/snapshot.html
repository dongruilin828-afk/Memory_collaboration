我问你个题：题库一共有 m 道题，考官随机抽取 n 道，我可以选择其中的 q 道作答，如果我至少有 80% 的概率能全部做对我选的q道题，那么我应该背多少道题？（做出假设：我没背的题一定丢分）？（1≤q≤n≤m）

这是一个非常经典的超几何分布（Hypergeometric Distribution）概率问题。我们可以通过把问题进行数学建模来寻找最优解。

一、 问题建模与转化

  1. 设定变量：

    • 题库总题数：mmm

    • 你背诵的题数：kkk（这是我们需要求解的目标）

    • 考官随机抽取的题数：nnn

    • 你需要作答的题数：qqq（满足 1≤q≤n≤m1 \le q \le n \le m1≤q≤n≤m）

  2. 核心逻辑： 设考官抽出的 nnn 道题中，恰好包含 xxx 道你背过的题。

    • 能全部做对的条件：只要抽出的 nnn 道题中，你背过的题数量大于或等于 qqq（即 x≥qx \ge qx≥q），你就可以从这堆会做的题里挑选 qqq 道进行作答，从而做到全部做对。

    • 目标概率：我们需要保证 x≥qx \ge qx≥q 的概率至少为 80%，即：

      P(X≥q)≥0.8P(X \ge q) \ge 0.8P(X≥q)≥0.8

二、 数学公式与计算

变量 XXX 服从超几何分布，其概率质量函数为：

P(X=x)=(kx)(m−kn−x)(mn)P(X = x) = \frac{\binom{k}{x} \binom{m-k}{n-x}}{\binom{m}{n}}P(X=x)=(nm​)(xk​)(n−xm−k​)​

因此，“至少有 qqq 道题是你背过的”总概率为：

P(X≥q)=∑x=qmin⁡(n,k)(kx)(m−kn−x)(mn)≥0.8P(X \ge q) = \sum_{x=q}^{\min(n, k)} \frac{\binom{k}{x} \binom{m-k}{n-x}}{\binom{m}{n}} \ge 0.8P(X≥q)=x=q∑min(n,k)​(nm​)(xk​)(n−xm−k​)​≥0.8

三、 如何求解 kkk？

由于这是一个关于 kkk 的离散组合求和不等式，没有简单的初等显式解析解，但在实际应用中可以通过以下两种方式得出答案：

1. 编程快速求解（推荐）

如果你需要精确数值，用 Python 的 scipy 库可以瞬间算出来：

Python
from scipy.stats import hypergeom


def calculate_k(m, n, q, target=0.8):
  for k in range(q, m + 1):
    # 计算 P(X >= q)，其中总体为 m，背了 k，抽样 n
    prob = 1 - hypergeom.cdf(q - 1, m, k, n)
    if prob >= target:
      return k
  return m

2. 两种特殊情况的直观分析

  • 极端情况（全必答：q=nq = nq=n）： 如果你抽几道题就必须全做几道题，那么抽出的 nnn 道题必须全部在你背的 kkk 道题之内。此时公式简化为：

    (kn)(mn)≥0.8\frac{\binom{k}{n}}{\binom{m}{n}} \ge 0.8(nm​)(nk​)​≥0.8

    这种情况下，为了达到 80% 的把握，你需要背下题库中很大比例的题目（通常接近总题数的 80% 甚至更高，取决于 mmm 和 nnn 的大小）。

  • 有挑选空间（q<nq < nq<n）： 如果你只需要从 nnn 道题里挑 qqq 道会做的，你的容错率会大大增加。例如 nnn 很大而 qqq 较小时，你不需要背全所有题，只需确保抽出的题里“凑够 qqq 道会做的”概率达标即可。

如果你手头有具体的数值（比如 m=100,n=10,q=5m=100, n=10, q=5m=100,n=10,q=5），代入上述求和公式即可算出你精确需要背多少道题。

import math

def comb(n, r):
    if r < 0 or r > n:
        return 0
    return math.comb(n, r)

m = 12
n = 9
q = 6

for k in range(q, m + 1):
    # Total ways to choose n from m
    total_ways = comb(m, n)
    # Ways to choose x known questions (where x >= q) and (n - x) unknown questions
    favorable_ways = 0
    for x in range(q, min(n, k) + 1):
        favorable_ways += comb(k, x) * comb(m - k, n - x)
    prob = favorable_ways / total_ways
    print(f"k = {k}, favorable = {favorable_ways}, total = {total_ways}, prob = {prob:.4f}")

  • 因此，只要你背了 9 道题，无论考官怎么抽，抽出的题目里必然包含至少 6 道你会做的题，概率直接达到 100%。

    // 使用对数阶乘计算组合数，防止极大数值（如 100! ）在 JS 中溢出
    function logComb(n, k) {
        if (k < 0 || k > n) return -Infinity;
        if (k === 0 || k === n) return 0;
        if (k > n / 2) k = n - k;
        let res = 0;
        for (let i = 1; i <= k; i++) {
            res += Math.log(n - i + 1) - Math.log(i);
        }
        return res;
    }

    // 计算超几何分布 P(X >= q)
    function calcProbability(m, n, k, q) {
        if (q > n || q > k) return 0;
        if (k >= m - n + q) return 1; // 边界情况：背得足够多，盲抽也必然凑够 q 题

        let totalLog = logComb(m, n);
        let prob = 0;
        for (let x = q; x <= Math.min(n, k); x++) {
            let pLog = logComb(k, x) + logComb(m - k, n - x) - totalLog;
            prob += Math.exp(pLog);
        }
        return Math.min(prob, 1);
    }
