### 断点续传核心缺陷：旧译文丢失

AI 指出每次运行 canvas.Canvas(OUTPUT_PDF) 会新建 PDF，前面 start_page-1 页只生成空白页，不会接回上次翻译内容；升级需修复此逻辑，否则最终 PDF 前段空白。

- 来源消息：1, 2

### 额度耗尽时页码保存语义错误

AI 指出额度耗尽分支调用 save_progress(current_page_num)，但 last_finished_page 语义是最后完成的页；建议保存 current_page_num - 1 并在加载时 +1，以避免语义混乱。

- 来源消息：1, 2

### API 请求长度控制不准确

AI 指出 split_text 的 max_len=4500 不能保证百度 API 一定安全，涉及参数长度、字符计数规则；建议按段落→句子→每批 3000~4000 字符切分。

- 来源消息：1, 2

### 未复用 requests.Session

AI 指出每次 requests.post 独立请求，几百页数千次调用应使用 requests.Session() 复用连接。

- 来源消息：1, 2

### 本地额度统计不等于百度实际计费

AI 指出 total_cost += len(b.strip()) 统计本地发送字符长度，可能不等于百度实际计费；MONTHLY_FREE_QUOTA 最好理解为本程序保守估算，若 API 返回实际消耗应优先采用。

- 来源消息：1, 2

### PDF 段落结构被破坏

AI 指出 full_text = " ".join(w["text"] for w in words) 合并文字破坏了原 PDF 段落、章节标题等结构；小说翻译应保留段落、空行、标题、页码、首行缩进等。

- 来源消息：1, 2

改为每页翻译结果缓存，随时可以从缓存重建输出 PDF；崩溃、中断或额度耗尽后已完成内容不会变成空白页。

- 来源消息：3, 4

### 月度额度管理

月度免费额度为 1,000,000 字符；额度文件以当前月第一天字符串作为月份标识，跨月自动重置；额度文件损坏时重新初始化。

- 来源消息：3, 4

### 断电恢复的额度校正

sync_quota_from_cache 会在启动时根据成功缓存页面的 status 和 usage_month 校正已用额度，解决 API 成功→页面缓存保存→额度文件保存前断电导致额度丢失的问题；add_used_chars 注释警告不要再次调用 sync_quota_from_cache，以免重复计算当前页。

- 来源消息：3, 4

### 页面缓存校验

每页缓存文件为 page_XXXX.json，保存 source_hash、translated_text、cost_chars、usage_month、status 等；加载缓存时要求 status 为 completed 且 source_hash 与当前提取文本一致，避免更换 PDF 后误用旧缓存。

- 来源消息：3, 4

### API 重试策略

百度 API 请求最多重试 3 次，指数退避时间为 2^attempt（约 2、4、8 秒），连续失败后抛出 RuntimeError。

- 来源消息：3, 4

### PDF 排版与页脚

使用 STSong-Light 字体，字号 11、行高 16、边距 30、页脚字号 8；wrap_text_to_lines 根据 stringWidth 自动换行，英文优先在最近空格处断行；每页页脚显示“原 PDF 第 x 页”，续页时加“（续）”。

- 来源消息：3, 4

### 重建 PDF 的连续性保护

rebuild_output_pdf 顺序遍历页面，一旦某一页缓存缺失就停止输出，避免出现 1、2、3、5 页有而第 4 页缺失时输出 PDF 页码错乱。

- 来源消息：3, 4

### 主翻译流程逻辑

translate_pdf_resumable 依次检查输入文件、sync_quota_from_cache、加载进度、遍历每一页；A 提取文字失败或 D 额度不足时都会调用 rebuild_output_pdf 并保存进度后返回；B 有有效缓存跳过；C 空白页写入空缓存并更新进度。但代码在 D 额度不足处理 return 后截断，后续循环体和主函数结束未知。

- 来源消息：3, 4

### 原版断点续传缺失导致空白页问题

AI指出原代码重新创建PDF时会将前面页面变成空白页，建议改为按页缓存到translation_cache目录（page_0001.json等），再次运行时直接读取缓存，不再浪费百度额度并从断点继续翻译。

- 来源消息：3, 4

### 缓存增加source_hash校验

AI建议在每页缓存中加入source_hash（每页文本的SHA-256），当PDF文件版本变化但文件名相同时，通过比较hash避免错误使用旧翻译缓存。

- 来源消息：3, 4

### 分句方法优化避免缩写切错

AI指出原代码使用text.replace('\n',' ').split('. ')切分句子，容易把Mr. Potter、Mrs. Weasley、Dr.等缩写切错，建议先处理常见缩写，再根据句子边界和长度进行分块。
