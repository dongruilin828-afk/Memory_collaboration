Skopos /ˈskoʊpɒs/ 是一个源自希腊语的学术术语，意思是 目的、目标、意图。

它最常出现在**翻译学（Translation Studies）**中。

📚 Skopos Theory（目的论）

Skopos Theory = 翻译目的论

核心思想是：

翻译的方法应该由翻译的目的（purpose）决定。

也就是说，翻译并不一定要逐字忠实于原文，而应该根据译文要达到什么目的、面向什么读者、使用什么场景来决定翻译策略。

例如：

原文：

Mind the gap.

如果目的是地铁里的提示语，可以翻译成：

小心站台间隙。

而不是机械地翻译成：

“注意这个间隔。”

因为前者更符合译文的实际功能和目的。

常见相关词

  • Skopos Theory → 目的论
  • translation purpose → 翻译目的
  • target audience → 目标读者 / 受众
  • translation strategy → 翻译策略
  • source text (ST) → 原文 / 源文本
  • target text (TT) → 译文 / 目标文本

📌 一句话记忆：

Skopos = purpose（目的）

在翻译学里：

The purpose determines the translation strategy.
→ 翻译目的决定翻译策略。
