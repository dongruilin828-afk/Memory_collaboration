题目翻译

1（30 分）. 设字母表 Σ={0,1}，语言 L={0,01}。
(a) 列出 L2=LL 中所有字符串（即所有形如 xy，其中 x,y∈L 的串）。
(b) 空串 ε 是否属于 L∗？ε 是否属于 L+？
(c) 列出 L∗ 中长度不超过 3的全部字符串。

解答

(a) L2=LL

L={0,01}，把每个 x∈L 和每个 y∈L 拼接：
  • x=0,y=0：0⋅0=00
  • x=0,y=01：0⋅01=001
  • x=01,y=0：01⋅0=010
  • x=01,y=01：01⋅01=0101
L2={00,001,010,0101}

(b) L∗ 和 L+ 的定义

  • L∗（Kleene 星）：L∗=⋃n≥0​Ln，规定 L0={ε}。
    ε∈L∗，是。
  • L+（正闭包）：L+=⋃n≥1​Ln，只包含 1 次及以上拼接，不含 L0。
    ε∈/L+，不是。
一句话记忆：星闭包包含空串，正闭包不包含空串。

(c) L∗ 里长度至多为 3 的串

长度≤3，即长度 = 0、1、2、3。
  • 长度 0：ε
  • 长度 1：只能用 L 里长度 1 的串：0
  • 长度 2：来自 L2 中长度为 2 的串：00
  • 长度 3：拼接若干 L 中的元素，总长度 = 3：
    1. 0+0+0=000
    2. 0+01=001
    3. 01+0=010
汇总全部：
{ε,0,00,000,001,010}
校验：
  • 01 长度为 2，来自原始集合L，哦刚才漏掉！
    修正：
    长度 2 还有 01（来自L1）
✅ 完整集合：
长度 0：ε
长度 1：0
长度 2：00,01
长度 3：000,001,010
{ε,0,00,01,000,001,010}

最终汇总答案

(a) L2={00,001,010,0101}
(b) ε∈L∗（是）；ε∈/L+（否）
(c) 长度至多 3：{ε,0,00,01,000,001,010}

题目翻译

2（30 分）考虑下面这个问题：给定一个正整数n，以 ** 二进制（高位在前）** 形式写出，判定n能否被 3 整除。
(a) 将这个问题形式化为语言 L⊆{0,1}∗。也就是精确描述字符串集合L。
(b) 假设n改用 ** 一元编码（unary）** 给出（即由n个1组成的字符串）。简要解释为什么这个问题仍然可以表示为语言 L′⊆{1}∗。

解答

(a)

L 是所有表示能被 3 整除的正整数的二进制字符串（最高位在前，正整数，所以字符串不能是空串，且不能有前导 0）。
数学描述：
L={w∈{0,1}∗​w 是不含前导0的非空二进制串，且它代表的正整数 val(w)mod3=0}
举例：
11 = 3，110 = 6，1001 = 9，这些都属于L；
1=1，10=2 不属于L。
补充说明：
  • 不包含空串，因为题目限定是正整数；
  • 不允许前导零，比如串011不算，因为011不是合法的 “高位在前书写的正整数二进制”。

(b)

一元编码（unary）规则：数字n 写成由 n 个字符1组成的串。
例如：n=3 对应字符串 111；n=6对应111111。
定义语言：
L′={k times11⋯1​​∣k>0,kmod3=0}
也就是 L′ 是所有由 3 的倍数个1构成的非空字符串。
简要解释：
在一元表示下，字符串里1的个数就等于数值n。判定n能否被 3 整除等价于：判断输入串中1的总数是不是 3 的倍数。所有合法输入都是只由1构成的串，因此这个集合 L′ 是 {1}∗ 的一个子集，所以可以表示成 L′⊆{1}∗。

L={w∈{0,1}∗:w starts with 0 and ends with 1}.

 网站上运行的代码。
语言含义：所有由 0、1 构成的字符串，以 0 开头，并且以 1 结尾。
例：01∈L,001∈L,011∈L,0101∈L；
不属于：ε,1,0,00,10,110。

DFA 设计（确定有限自动机）

状态定义

  • q0​：起始状态，还没有读到任何字符
  • q1​：已经读到第一个字符是0（开头成功），最后读到的字符是 0
  • q2​：已经读到第一个字符是0（开头成功），最后读到的字符是 1 → 接受状态（final state）
  • q3​：已经读到第一个字符是1（开头失败，任何后续串都不可能属于 L，死状态）
字母表 Σ={0,1}

转移函数 δ

  1. δ(q0​,0)=q1​ 读到第一个字符 0 → 进入 q1
  2. δ(q0​,1)=q3​ 读到第一个字符 1 → 进入死状态 q3
  3. δ(q1​,0)=q1​ 已经以 0 开头，末尾新读 0，末尾变成 0
  4. δ(q1​,1)=q2​ 已经以 0 开头，末尾新读 1，末尾变成 1（接受态）
  5. δ(q2​,0)=q1​ 已经以 0 开头，末尾新读 0，末尾变成 0
  6. δ(q2​,1)=q2​ 已经以 0 开头，末尾新读 1，末尾保持 1（接受态）
  7. δ(q3​,0)=q3​ 死状态，读任何字符留在死状态
  8. δ(q3​,1)=q3​
起始状态：q0​
接受状态集合：F={q2​}

  • 箭头指向 q0​（起点）
  • q0​0​q1​,q0​1​q3​
  • q1​0​q1​,q1​1​q2​
  • q2​0​q1​,q2​1​q2​ （q2​画双层圆圈，表示终态）
  • q3​0​q3​,q3​1​q3​
