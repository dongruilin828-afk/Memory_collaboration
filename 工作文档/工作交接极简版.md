# 工作交接文档

个人觉得我已经把这个项目做到这步，大家应该已经会很轻松了[旺柴]，所以希望大家起码把这个极简版交接文档稍稍阅读一下，里边一些很简单的工作稍微做一做，我相信我们队员的工作量应该是整个思政大课里面最少的[捂脸]。

## 主要内容

1. 项目使用 **uv 环境** 构建，可以下载一下，很轻量很好用，一问 AI 就知道怎么下载。

2. 不建议 agent 可以未经你允许执行 commit。

3. **不允许** agent 自己创建新分支，你可以明确告诉他“我要创建……”让他代劳，但是不允许他偷着自己开。

4. 建议允许 agent 阅读 GitHub 上所有有用的公开内容。

5. agents.md 是一个在开始工作前先让 agent 阅读并牢记的东西，因人而异，我后续会把我的发给你们。

6. 每个人改自己的部分的时候 **尽量新开分支改**。

7. 现在可被总结的 AI 有：ChatGPT、豆包、DeepSeek。

8. 可用的 API 提供商：Google AI studio、Silicon Flow、DeepSeek。

9. 在开始工作前，建议先 **玩一玩我发出的 v1.0.0 版本**，多按一按上面的按钮熟悉一下功能，对本项目做一个最基本的了解。

10. 我们分为 **分享链接抓取总结** 和 **选取文件直接总结** 两种方式，后者 **支持拖拽**。

11. 我们已经支持让用户自己选择 API 调用顺序，比如用户希望先使用 Silicon 再使用 Gemini 两者都用到限额后再使用 DeepSeek。

12. 日常测试（这会弹出 GUI 界面）：在项目根目录下开 PowerShell 运行：uv run python -m gui.app

13. 直接总结功能只接受 UTF-8 的 `.md`/`.txt`，文件必须非空且不超过 10 MB。

14. 我们尽量做**定点修改**，在修改自己负责的内容时不搞坏其他内容，在这个过程中，Codex 的插件 **ponytail** 比较好用，建议安装。

15. 跑测试的时候一定要仔细检查， 程序会犯各种你意想不到的错误，比如写有图片但是不给你下载，比如下载之后把图片给你放反，比如假装自己抓取了文档但只是一行字，比如这次能抓取到下次又抓不到了…… 即使你让 AI 检查也建议你 **自己简单溜一遍**，有时候 Codex 真的会骗你。

16. 有时候抓取对话抓不全，可能是浏览器“懒加载”问题，他不一下子给你翻到最上面，这 bug 已经修复但不代表不会复发。

17. 有时候总结会 **把你对话中的某个文档拆成好几个主题**，该问题要尤其注意，很有可能复发。

18. “工作交接”完整版可直接喂给 AI。
